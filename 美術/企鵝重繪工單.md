# 工單：把定版企鵝設定稿變成遊戲用戰鬥幀（先做拳擊手）

## 你是誰、要交什麼

你不是在畫圖，你是在**寫一支可重跑的參數化繪製程式**。
交付物有兩個，缺一不可：

1. `tools/繪製企鵝.py` — 純 Python（Pillow，已安裝），跑一次就重新產出全部幀
2. `assets/frames_boxer/*.png` — 由上面那支程式產出的 17 張幀

**絕對不要手工修圖然後把結果存進去。** 專案規矩：素材必留建構腳本，烘死＝之後無法改。
之後要調一條線、換一個顏色，必須是改參數重跑，不是重畫。

## 參考圖（定版，不可改設計）

`assets/ref/企鵝設定稿_拳擊手.jpeg` — 三視圖（正面／側面／背面），作者是委託人朋友的小孩，
**設計本身是定版**。你的工作是把它轉成遊戲能用的形式，不是重新設計它。

造型要素（照抄，不要自由發揮）：
- 企鵝，蛋／梨形身體。頭與背黑色，臉與肚白色
- **紅色頭帶**，側邊打結，**兩條長飄帶**
- **紅色拳擊手套**，圓潤連指手套形，有袖口
- **紅色背心**（連身，肩帶過肩，蓋住腹部）
- **米橘色大腳掌**，外八，三趾
- **小的橘黃色喙**
- **兇臉**：粗黑眉毛與眼睛連成一塊，斜向下

## 遊戲的硬規格（不符合就是不能用）

- 尺寸 **512×512 RGBA PNG，透明背景**
- 角色**水平置中，中心 x ≈ 256**（誤差 ±12）
- **腳底 y ≈ 460**（誤差 ±8）← 這條最重要，錯了角色會浮空或陷進地板
- 角色高度約 **400~430 px**（出拳等伸展動作寬度可到 390，其餘約 262~290）
- 這些數字是從現有幀 `assets/frames/idle_1.png` 等量出來的，可自行複驗

## 畫風規格（跟現有 16 隻角色一致，不是照搬參考圖的畫法）

參考圖是柔和厚塗＋鉛筆稿線，**遊戲裡角色只有約 50 px 高，那個畫法會糊成一團**。
所以：

- **平塗**，每個材質 3~4 階（本色／暗部／亮部／可選反光），不要漸層
- **統一深色描邊**（深棕或近黑），線寬隨尺寸一致
- 不要保留 construction line、影線、鉛筆質感

## ★ 四個一定要處理的可讀性問題（在 50 px 下會壞掉）

1. **手套與背心同一個紅，會糊在一起。**
   對拳擊手來說手套就是武器，必須是畫面上最好讀的移動物件。
   → 手套維持紅色但**明度壓深一階**，並加一圈**明確的淺色袖口**跟背心切開。
2. **正面看不到白肚子。** 現有角色靠白色塊辨識。
   → 背心開口低一點，讓白色從臉延伸到胸口露一截。
3. **剪影是光滑的蛋，小尺寸不好認。**
   → 讓頭帶飄帶在**正面也往外甩開**，用它破頭部剪影。
4. **腹肌用細影線會消失。** 要留就留 2~3 條粗線，或直接不畫。

## 要產出的 17 張幀

檔名固定，遊戲靠檔名載入：

| 檔名 | 內容 |
|---|---|
| `idle_1` `idle_2` | 待機呼吸兩幀，重心微起伏 |
| `walk_1`~`walk_4` | 走路循環四幀（腳交替、身體上下彈） |
| `punch_1` `punch_2` `punch_3` | 出拳三幀：收手 → 伸出（手套要伸到畫面外側，寬度可到 390）→ 收回 |
| `grab_1` `grab_2` | 雙手前伸抓握兩幀 |
| `hurt_1` `hurt_2` | 受擊：身體後仰、眉毛變形、飄帶前甩 |
| `dash_1` `dash_2` | 衝刺：身體前傾、飄帶大幅後拖 |
| `ko_1` | 倒地 |
| `stance_1` `stance_2` | 架式（蓄勢）：下沉、拳頭舉高護臉，兩幀微呼吸 |

角色一律**面向畫面右方**（遊戲會自行水平翻轉），三／四分之三正面視角。

## ★ 架構要求：企鵝本體與裝備要分開

委託人明講「**以後以這個企鵝當 REF 畫其他的**」。所以程式要拆成兩層：

- **企鵝本體**（身體、頭、臉、喙、眼、腳）＝ 所有 16 個職業共用
- **裝備層**（頭帶、手套、背心）＝ 拳擊手專屬，用參數描述

之後要做武士，就是換一組裝備參數（髮髻、刀、道服），本體不動。
請把裝備設計成一個資料結構（例如 `GEAR = { 'boxer': {...} }`），不要寫死在繪製流程裡。
