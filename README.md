# Penguin Can Fight

**線上直接玩：https://welkinhung7797-cloud.github.io/roubochang/**

16 隻功夫企鵝 × 全近戰擂台 × 波次生存。武器全自動攻擊，但**走位本身就是搓招**——這是一個自動戰鬥卻能打連段的遊戲。

## 核心：三態與奧義

你的行動只有三種，每一種都是招：

| 狀態 | 觸發 | 例子 |
|---|---|---|
| **站樁技** | 站定不動 0.5 秒自動生效 | 化勁架式（挨打自動摔人）、寸勁蓄力、金鐘罩、震腳、吐納 |
| **移動技** | 持續移動自動生效 | 旋風連腿、搖擺身法、疾風步、曳尾勁、威壓步 |
| **衝刺技** | 按 Space，衝刺瞬間帶攻擊 | 擒抱衝刺（扛人撞牆）、迴旋抓摔、縮地、飛膝突進、醉步翻滾 |

三招都能在波間商店購買與更換，任何企鵝裝任何招。

**奧義＝用走位搓出來的必殺。** 站定滿 0.7 秒記一個「站」拍、持續移動滿 0.7 秒記一個「移」拍；湊齊自家指令再按 Space，衝刺技就變成奧義。例：摔角企鵝的「巨螺旋墜擊」＝站·站·站＋衝，抓住敵人掄三大圈扔出去炸全場。沒湊齊指令也有通用加成：每個站拍讓這次衝刺傷害 +25%，每個移拍讓冷卻 -15%。

16 隻企鵝各有專屬奧義與指令：無影連打（拳擊）、一擊必倒（空手道）、拔刀燕返（劍豪）、分身亂舞（忍者）、大迴環（太極）、圓相返技（合氣道）、血祭（狂企鵝）、隕石頭槌（鐵頭）……角色選擇畫面都查得到。

## 其他內容

- 16 隻功夫企鵝職業（品種與配件各不同），對手是可愛妖怪軍團（更新中）
- **攻擊實體化**：拳影、刀光、掌風是真的飛出去的東西，碰到敵人那一幀才有傷害；配頓幀、受擊壓扁、命中火花與力度分層音效
- **前期格鬥、後期割草**：前期單怪扛得住一整套連段（受擊硬直讓連段鎖得住人、連壓太久觸發霸體），build 成型後才輾壓
- 27 把近戰武器（各 4 階可合成）、41 個商店道具、**24 件升級裝備**（升級不給裸數字，給鬼手甲、鐵下巴、迴力腰帶這種觸發型裝備）、12 種敵人 + 2 隻頭目
- 20 波，第 10 與第 20 波是頭目戰；危險等級 0 到 5，通關解鎖下一級
- 純前端、零外部依賴、零 CDN，離線可跑

## 本機怎麼跑

```
python -m http.server 8746
```
瀏覽器開 http://localhost:8746/ 。直接雙擊 `index.html` 也能跑。

## 檔案結構

```
index.html          外殼、全部樣式、固定舞台等比縮放
src/data.js         職業／武器／道具／敵人／波次曲線（所有數值旋鈕在這）
src/engine.js       戰鬥、敵人 AI、波次、商店、存檔
src/render.js       Canvas 繪圖（幾何程序繪製，無圖片資產）
src/ui.js           選單／角色選擇／升級／商店介面 + 主迴圈 + 測試機器人
tools/              平衡量測腳本（Node，不需瀏覽器）
```

## 操作

WASD 或方向鍵移動、Space 衝刺——就這樣，全部的操作。武器自動攻擊，站樁技與移動技自動觸發，
連段靠走位節奏搓出來（畫面右下有節拍條與奧義指令對照）。
Esc 暫停；升級畫面按 1 到 4 選裝備；商店按 R 重骰、Enter 進下一波；招式從第 2 波起會出現在商店，買了在裝備欄點擊換上。

## 全近戰帶來的設計後果

沒有遠程武器不只是換皮，它改變了整個威脅結構，以下三點是實測後才定案的：

1. **近戰射程是命脈**。第一版射程 62（接觸受傷距離是 28），實測輸出效率只有理論值的三成——玩家根本不敢進場。射程整體上調 38% 後才成立。射程是這個遊戲最敏感的數值，改動前先跑診斷。
2. **反傷型敵人必須是騷擾，不能是牆**。刺蝟原本每次被打反彈全額傷害，在沒有遠程解的前提下＝無解硬殺。現在改成有 0.6 秒冷卻、成長走平方根、單次不得超過玩家最大生命的 7%。
3. **遠程敵人是主要壓力來源**。投擲手在實測中長期是承傷第一名，這是對的——它逼玩家離開安全的風箏路線，是全近戰版本張力的來源。

## 平衡怎麼量的

不靠手感，靠 `tools/` 裡的三支腳本跑機器人。機器人會維持在自身最長武器的交戰距離、繞著打、依優先序購物、依權重選升級——模擬一個懂遊戲但不完美的玩家。

```
node tools\平衡_單職業逐波診斷.js boxer 0 4242     單一職業逐波：擊殺／輸出／承傷來源／同時在場
node tools\平衡_全職業快測.js 0 4242               15 職業各跑一局
node tools\平衡_多種子通關率.js 5 4                每職業 4 個種子，看通關率
```

最近一次量測（機器人，每職業 4 局，量測對象＝目前這版三態＋奧義系統）：

| 危險等級 | 整體通關率 | 說明 |
|---|---|---|
| 0 | 約 95% | 幾乎全職業全勝（狂人補了基礎吸血後脫離谷底） |
| 5 | 約 80% | 太極／狂人／大力士 50-75%，脆皮與站樁流在高難度吃力 |

機器人會看時機衝刺、奧義就緒立刻放、依站樁技類型決定何時站著不動（有投擲手在場就不死站），
所以三態與奧義的強度都在量測範圍內。已知量測盲點：機器人不會為了湊指令刻意演奏節拍，
奧義觸發頻率比會玩的真人低，實際玩家強度會再高一截。

同種子必須完全可重現，跑 `node tools\驗證_同種子可重現.js` 檢查；不一致代表有跨局殘留狀態，
那會讓上面這張表變成假數據（已踩過一次：`G.time` 沒歸零）。

脆皮高爆職業在高難度會死、坦系穩定通關——這個分布是刻意的。
機器人走位是完美的，真人會更難；反過來機器人的 build 判斷比真人差，兩邊大致抵銷。

## 主要數值旋鈕（都在 data.js）

| 旋鈕 | 現值 | 影響 |
|---|---|---|
| `enemyScale` 血量底數 | 1.10 | 全域難度主旋鈕。第 20 波約 5 倍血 |
| `waveBudget` | 14 + 3w + 0.8w² | 同時在場的壓力。平方成長＝後期被淹沒的手感 |
| `ZOOM`（render.js） | 2.0 | 人物在螢幕上多大。這是「肉搏感」的主旋鈕，不是美術細節 |
| 武器 `range` | 63 至 177 | 見上面第 1 點，最敏感 |
| 素材成長 | 1 + 0.05w | 必須跟得上商店通膨（每波 +11%），否則後期買不起 |

血量與數量的乘積（整波總血量）要維持在玩家該波總輸出的七成上下。單獨調任一邊都會壞。

## 已知缺口

- **沒有背景音樂**（音效已有）。
- **沒有武器流派套裝加成**。每把武器都有 `klass`（拳／腿／刃／摔技／軟兵等）欄位但目前沒用上；
  「同流派湊三把給加成」是下一輪最值得加的深度，資料結構已經預留好。
- 奧義指令固定綁職業，沒有做「自訂指令」或「多奧義」；節拍上限三拍。
- 全部 16 隻企鵝一開始就能選，沒有做角色解鎖進程。
- 頭目只有 2 隻（還是人型，沒改成大狗），第 20 波之後沒有無盡模式。
- 手機／觸控未支援，版型固定 1280×720 等比縮放。
- 數值是本專案自行重建的，不是任何既有作品的數據。

## 開發注意

- 改完 `src/*.js` 一律先 `node --check`，再跑一次 `tools/平衡_單職業逐波診斷.js` 確認沒把曲線改壞。
- `window.__test` 是開發用鉤子：`__test.start(職業id, 危險, 種子)`、`__test.simulate(...)`、`BOT.on = true` 讓機器人接手。
- 分頁切到背景時 `requestAnimationFrame` 會停，遊戲跟著暫停——這是正確行為，不是 bug。
