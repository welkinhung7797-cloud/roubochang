# Penguin Can Fight 美術總規格 v1

本文件是所有美術產出的最高規範。與個別規格衝突時以本文件為準。

## 世界觀一句話

雪山武館的功夫企鵝，用練出來的氣勁，打飛來踢館的各路可愛妖怪。

## 風格錨定

- 貼紙風平塗插畫：厚深色描邊（近黑褐色）、白色貼紙外框、無漸層陰影堆疊（允許簡單兩階色）
- Q 版比例:頭佔全身 50-60%、大眼（含高光）、圓輪廓、短手短腳
- 情緒：可愛、有精神、有喜感。**禁止**：恐怖、血腥、哭臉、寫實風
- 背景：純白（後製會去背）
- 構圖：全身、四分之三正面視角、置中、佔畫面約 70%

## 硬性禁令

1. 圖中不得出現任何文字、浮水印、簽名
2. 不得模仿任何具名 IP 的識別設計（任何知名企鵝角色、知名幽靈角色的招牌特徵）
3. 敵人不得有令人不適的元素：無血、無腐爛細節、無恐怖表情——殭屍是「綠色貼 OK 繃的呆萌殭屍」不是恐怖殭屍

## 檔案規範

- 格式：PNG，白底（由總工程師的管線統一去背，交付白底即可）
- 尺寸：1024×1024 以上
- 命名：全部小寫英文＋底線，見各分規格
- 交付路徑：`交付/` 下的指定子資料夾。**不得寫入 src/、assets/ 或其他任何專案資料夾**

## 驗收

交付後由 `tools/驗收_部件.py` 機器稽核（存在／尺寸／格式／內容非空），
未過閘的檔案會產生退件單 `交付/退件單.md`，依單重做。
